# Фронтенд кредитного кабинета

Веб-интерфейс клиента и кредитного аналитика по `FRONTEND_SPEC.md`. React 18, TypeScript strict, дизайн-система Альфа-Банка `@alfalab/core-components`, данные через TanStack Query, моки на MSW.

## Запуск

```bash
cd frontend
cp .env.example .env
npm ci
npm run dev        # http://localhost:5173
```

Через Docker вместе с бэкендом из корня репозитория:

```bash
docker compose up --build   # фронтенд на http://localhost:8080
```

## Переменные окружения

| Переменная | Значение |
|---|---|
| `USE_MOCKS` | `true`: демо-учётки обслуживает MSW прямо в браузере, всё остальное идёт на бэкенд. `false`: моков нет |
| `DEMO_MODE` | `true`: панель «Войти как…» и код подтверждения рядом с полем |
| `VITE_API_PROXY_TARGET` | куда dev-сервер проксирует `/api`, по умолчанию `http://localhost:8000` |

### Как устроены моки

Моки включаются только для демо-учёток: вход под почтой из списка ниже, запросы с демо-токеном `mock-token.*`, код демо-приглашения `4821-KX`. Запросы реальных пользователей MSW пропускает на бэкенд без изменений. Демо-данные сохраняются в `localStorage`, сбросить их можно кнопкой в демо-панели.
