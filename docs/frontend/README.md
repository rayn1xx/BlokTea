# Фронтенд кредитного кабинета

Веб-интерфейс клиента и кредитного аналитика по `FRONTEND_SPEC.md`. React 18, TypeScript strict, дизайн-система Альфа-Банка `@alfalab/core-components`, данные через TanStack Query. Все данные приходят с бэкенда, моков в браузере нет.

## Запуск

```bash
cd frontend
cp .env.example .env
npm ci
npm run dev        # http://localhost:5173
```

Через Docker вместе с бэкендом из корня репозитория:

```bash
docker compose up --build   # фронтенд на http://localhost:8080
```

## Переменные окружения

| Переменная | Значение |
|---|---|
| `VITE_API_PROXY_TARGET` | куда dev-сервер проксирует `/api`, по умолчанию `http://localhost:8000` |

Код подтверждения показывается рядом с полем ввода, если на бэкенде `DEMO_MODE=true` (поле `demo_code` в ответе challenge).

## Структура

Код разложен по бизнес-доменам: `features/<домен>/` с файлами `types.ts`, `api.ts`, `hooks.ts`, папками `components/` и `screens/`. Общее лежит в `shared/`, сборка приложения в `app/`. Подробно в [architecture.md](architecture.md).
