# ИИ-задачи: модели, запуск, замеры

Раздел 8 ТЗ. Кредитное решение, баллы и суммы считает код; модель только извлекает поля из документов и
формулирует тексты. При любом сбое модели ответ остаётся на шаблонах (`text_source = 'template'`).

## Запуск

```bash
# в .env: LLM_ENABLED=true (остальные LLM_* см. .env.example)
docker compose --profile llm up
```

Сервис `ollama-init` скачивает `LLM_MODEL_TEXT` и `LLM_MODEL_VISION` в том `ollama-models` и завершается.
Пока модель не скачана, `/api/v1/health` отдаёт `llm: "down"`, задачи работают на шаблонах.
Если порт 11434 занят локальной Ollama, задайте `OLLAMA_PORT`.

Без профиля `llm` или с `LLM_ENABLED=false` модель не нужна: `/health` отдаёт `llm: "stub"`.

## Где что

| Задача | Код | Когда вызывается |
|---|---|---|
| И1, И2, И3 | `services/ai.py: analyze_document` | в фоне после загрузки документа (`status: analyzing`), `POST /documents/{id}/analyze` синхронно |
| И4 | `services/ai.py: recommendation_texts` | `POST /matching-sessions/{id}/recommend` |
| И5, И8 | `services/ai.py: decision_texts` | авторешение после submit, решение и предпросмотр аналитика |
| И6 | `services/ai.py: readiness_texts` | `GET /company/readiness` |
| И7 | `services/ai.py: analyst_summary` | `POST /bank/applications/{id}/ai-summary` |

Клиент Ollama: `integrations/llm.py`. Ответ строго JSON по схеме, валидация pydantic, одна повторная
попытка, кеш по хешу входа в памяти процесса. Для И3-И7 все числа в ответе сверяются со входом
(`numbers_mismatch` ведёт к шаблону). Суммы модели передаются в рублях, в API они в копейках.

В модель не уходят ФИО, паспорта и счета: паспорт не анализируется, название компании из резюме для
аналитика убирается (у ИП это ФИО).

## Модели

| Модель | Статус |
|---|---|
| `qwen3.5:9b` (Q4_K_M, 6,6 ГБ, Apache-2.0) | основная; проверена на всех задачах И1-И8, включая скан в PNG (И2). Нужна Ollama не старше 0.30 |
| `gpt-oss:20b`, `gpt-oss:120b` | не проверялись, только при мощной GPU |

Перед показом стоит прогнать 3-5 реальных сканов: И2 проверена на одном синтетическом.

## Замеры (CPU, без GPU)

Машина команды: 18 потоков, 15 ГБ ОЗУ, без видеокарты.

| Показатель | Значение |
|---|---|
| Память Ollama с загруженной моделью | 6,5 ГБ |
| Загрузка модели в память | 15 с (первый запрос после простоя 5 мин) |
| Скорость генерации | около 4 токенов/с |
| И6 готовность | 27-50 с |
| И4 рекомендация | 78-87 с |
| И5/И8 решение | 60-81 с |
| И7 резюме | 57-95 с |
| И1+И3 документ PDF | 166-217 с (в фоне) |
| И2 скан PNG | 149 с (в фоне) |

С `LLM_TIMEOUT_MS=30000` из ТЗ на таком CPU почти все задачи уйдут в шаблоны. Варианты: GPU,
`LLM_TIMEOUT_MS=180000` (запросы рекомендации, готовности и решения будут ждать модель до минуты и дольше)
или оставить 30 с и показывать шаблоны.
